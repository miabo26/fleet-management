# 🚚 برنامج حركة السيارات والمخازن الإقليمية

برنامج متكامل لإدارة حركة السائقين والشاحنات وجدولة وتوزيع المأموريات من المخزن الرئيسي إلى المخازن الإقليمية، مع متابعة خطوط السير والعهد المالية والوقود والصيانة.

---

## 📌 مواصفات المنظومة وبيانات التشغيل

### 1. شبكة المخازن ونقاط الحركة
* **المخزن الرئيسي (التحميل المركزي):** التجمع الخامس - القاهرة الجديدة.
* **جراج ومقر الأسطول:** شبرا - القاهرة (مبيت وفحص السيارات وانطلاق السائقين).
* **المخزن الإقليمي الأول (الدلتا):** محافظة الغربية - **القرشية** (مركز السنطة).
* **المخزن الإقليمي الثاني (مصر الوسطى):** **المنيا الجديدة - حي المستقبل**.
* **المخزن الإقليمي الثالث (مصر العليا):** محافظة **سوهاج - حي الكوثر**.

### 2. أسطول السيارات المعتمد (مع إمكانية الإضافة والتوسيع)
* **3 سيارات نقل صندوق:**
  1. كود `صندوق-01` (لوحة: ق أ ص 3819) - شيفورليه جامبو 7000
  2. كود `صندوق-02` (لوحة: ن ر ب 5142) - إيسوزو NPR صندوق عازل
  3. كود `صندوق-03` (لوحة: د س و 7628) - شيفورليه جامبو 8000
* **3 سيارات كانتر شاسيه طويل:**
  1. كود `كانتر-01` (لوحة: م ف ق 9264) - ميتسوبيشي فوزو كانتر شاسيه ممتد 6 متر
  2. كود `كانتر-02` (لوحة: ط ع ل 6183) - ميتسوبيشي كانتر FE 85
  3. كود `كانتر-03` (لوحة: س ج هـ 4821) - ميتسوبيشي فوزو كانتر اكسترا لونج HD
* **إمكانية التوسع:** نافذة مخصصة لإضافة شاحنات جديدة بأي عدد وتحديد مواصفاتها وحمولتها.

### 3. طاقم السائقين المعتمدين (6 سائقين)
1. **محمد رمضان** - سائق كانتر شاسيه طويل (رخصة درجة أولى)
2. **اسامة طلعت** - سائق سيارة نقل صندوق (رخصة درجة ثانية)
3. **محمد سمير** - سائق سيارة نقل صندوق (رخصة درجة ثانية)
4. **محمد عيد** - سائق كانتر شاسيه طويل (رخصة درجة أولى)
5. **السيد عيد** - سائق سيارة نقل صندوق (رخصة درجة ثانية)
6. **محمد ادب** - سائق كانتر شاسيه طويل (رخصة درجة أولى)
*(مع إمكانية إضافة وتعديل بيانات السائقين وأرقام هواتفهم والتراخيص)*

## 🌟 مميزات البرنامج

1. **لوحة مؤشرات حية (Dashboard):**
   * كروت أداء لحظية (عدد السيارات المتاحة، السائقين على الطريق، المأموريات النشطة).
   * جدول الحالة اللحظية لسيارات الصندوق وسيارات الكانتر وجاهزيتها.
   * أزرار سريعة لتغيير حالة الرحلة بنقرة زر (بدء التحميل ⬅️ انطلاق على الطريق ⬅️ تم التسليم ⬅️ إغلاق المأمورية).

2. **معالج إسناد المأموريات (Mission Dispatch):**
   * اختيار السائق المتاح والسيارة المتوافقة مع نوع رخصته (كانتر أو صندوق).
   * تحديد المخزن المستلم، مع احتساب تقديري للمسافة ومصروفات السولار والكارتات.
   * تسجيل رقم إذن الصرف أو الفاتورة، وتفاصيل وأوزان البضاعة.
   * صرف العهدة المالية وتحديد مواعيد الانطلاق والوصول المتوقع.

3. **طباعة أمر التشغيل والمأمورية الرسمية (Printable Trip Sheet):**
   * نموذج رسمي معتمد وجاهز للطباعة على ورق A4 أو حفظه كـ PDF بنقرة زر.
   * يشتمل على بيانات السيارة، السائق، خط السير، رقم إذن الصرف، وتفاصيل العهدة.
   * 4 توقيعات معتمدة: مسؤول الحركة، أمين المخزن الرئيسي، السائق، وأمين المخزن الإقليمي.

4. **خريطة تفاعلية لجمهورية مصر العربية (Leaflet Map):**
   * عرض مسارات الشحن المعتمدة (خط الدلتا، خط مصر الوسطى، خط الصعيد).
   * نقاط المخازن مع بيانات الاتصال للمسؤولين وحالة المأموريات القادمة إليها.

5. **إدارة العهد والمصاريف (Expenses & Settlements):**
   * متابعة مصاريف السولار الفعلي، الكارتات، وبدلات السفر.
   * احتساب صافي المتبقي من العهدة لتوريده للخزينة بنقرة زر.

6. **سجل الصيانة الدورية (Fleet Maintenance):**
   * تسجيل غيارات الزيوت، الفلاتر، تيل الفرامل، الكاوتش، ومتابعة عداد الكيلومترات.

## 🚀 طريقة تشغيل البرنامج

### الطريقة الأولى (الأسهل بنقرة واحدة):
* الضغط مرتين على ملف **`start.bat`** الموجود في مجلد المشروع.

### الطريقة الثانية (عبر الأوامر):
1. افتح موجه الأوامر (Terminal / PowerShell) في مجلد المشروع:
   ```bash
   npm run dev
   ```
2. افتح المتصفح على الرابط التالي:
   👉 **http://localhost:5173**
